🐛 Possíveis Problemas

Causa: Query mal formatada ou tabela/coluna inexistente

Solução: Verificar nomes das tabelas e colunas no Supabase

Causa: ID não existe ou peça não está ativa

Solução: Verificar se a peça existe e tem ativa = true

Causa: Políticas RLS bloqueando acesso

Solução: Configurar RLS para permitir SELECT público
