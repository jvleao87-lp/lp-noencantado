⚠️ Problemas a Verificar
1. Cards com IDs Iguais

Se todos os cards mostram o mesmo ID, o problema está na listagem.

2. URL Não Muda

Se a URL não mudar ao clicar, o problema está no clique.

3. Conteúdo Repetido

Se a URL mudar mas o conteúdo for igual, o problema está na página individual.
